# Phase 5 Screenshot Transcripts

These files are manual text transcriptions of the preserved Phase 5 CLI screenshots supplied from the project report.

They are intentionally kept separate from `verification/raw/` because they are **not direct terminal text captures**.

The screenshots show the successful/UP state of the Phase 5 fabric at the time those screenshots were taken.

- `vedge-prs1-screenshot-transcript.txt`
- `vedge-prs2-screenshot-transcript.txt`
- `vedge-prs3-screenshot-transcript.txt`
- `vedge-ldn1-screenshot-transcript.txt`
- `vedge-ldn2-screenshot-transcript.txt`
- `vedge-dc-dci-screenshot-transcript.txt`
- `vedge-drc-cyber2-screenshot-transcript.txt`

Only values readable from the screenshots are included. No missing values are invented.
