# Phase 4 Configuration and Onboarding Command Set

This directory contains the Phase 4 vEdge onboarding baseline and the operational command sets used to complete certificate installation and onboarding.

## Files

- `vedge-prs2-phase4-baseline.cfg` — system, VPN 0 transports and management VPN baseline
- `root-ca-install.txt` — Root CA download/install workflow
- `csr-generation.txt` — CSR generation workflow
- `device-certificate-install.txt` — signed certificate installation
- `identity-registration-reference.txt` — chassis/serial values verified for vEdge-PRS2
- `verification-commands.txt` — final onboarding verification commands

Sensitive material such as private keys, CSR bodies and certificate bodies is intentionally excluded.
