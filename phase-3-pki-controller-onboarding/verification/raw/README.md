# Phase 3 — Raw Verification Evidence

This directory contains preserved CLI output captured from the live controllers during Phase 3 verification.

The live lab has progressed beyond Phase 3, so some full control-connection outputs include vEdge sessions from later phases. The Phase 3 summary in `../observed-controller-state.md` filters those outputs to controller-to-controller relationships only.

Root CA live output is not included here. The public CA configuration is documented under `../../configs/root-ca.cfg`.
